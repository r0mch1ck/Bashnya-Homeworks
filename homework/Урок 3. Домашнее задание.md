# Задание 2. Операции над столбцами

Из предыдущего задания возьмите таблицу DAU с разбивкой по рекламным каналам. Проведите дополнительный анализ:

- ​Рассчитайте медианный DAU для каждого канала;
- Добавьте в фрейм столбец Total, в котором находится сумму DAU по всем рекламным каналам;
- Создайте новый фрейм, в котором вместо абсолютных значений DAU хранятся данные о процента DAU от Total. Например, для 1 апреля 2020 года BrainPlus составляет 627 / 1134 = 0.553 = 53% от Total;
- Постройте график истории изменения процента DAU. По оси x графика должны быть отложены даты, а по оси y - процент от общего DAU для каждого рекламного канала. График должен иметь тип "области с накоплением";
- Опишите ваши выводы и наблюдения.

# Задание 3. Модификация данных - apply и loc

В файле hw_lesson03_mau_region.xlsx хранятся данные о MAU. Проведите анализ и модификацию данных:

- ​Загрузите и изучите данные;
    
- С помощью команды .set_index('month') установите столбец month в индекс датафрейма;
    
- C помощью .loc поменяйте значение для столбца Africa в мае на 5000;
    
- Напишите функцию, которая вычисляет сумму MAU в столбцах Australia и Africa и проверяет, превышает ли эта сумма значение в столбце CIS.
    
    Если Australia + Africa > CIS, то функция должна возвращать сумму Australia + Africa, в противном случае, должен возвращаться 0. Примените функцию с помощью apply.
    
    **Подсказка**: не забудьте указать axis = 1;
    
- Создайте новый столбец 'EU превышает порог'. Он должен принимать значение True, в ситуациях, когда EU >= 4000 и False в противном случае.
    
    Постарайтесь решить это задание без apply, с помощью операций над столбцами.
