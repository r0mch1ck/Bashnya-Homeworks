# Задание 3. t-тест

- Установите уровень значимости 0.05;
- Задайте нулевую и альтернативную гипотезы;
- Проведите тест, получите p-value;
- Проверьте, можем ли мы отвергнуть нулевую гипотезу;
- Очистите выбросы из данных, постройте гистограммы и диаграмму размаха с разбивкой по каналам привлечения пользователей;
- Проведите t-тест еще раз для данных, очищенных от выбросов;
- Ответьте на вопрос: чем вызваны различия в результатах двух t-тестов?

На данных из урока мы могли бы исключить выброса таким образом:
```
outliers_limit = 0.95
report = purchases.groupby('user_id').agg({'ad_network': 'first', 'revenue': 'sum'})
for adn in report['ad_network'].unique():
	current = report.query('ad_network == @adn')['revenue']
	current = current[current < current.quantile(outliers_limit)] # исключаем выбросы
```
